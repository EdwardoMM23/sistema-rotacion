3. Cómo instalarla
1. Detén Flask con Ctrl + C.
2. Respalda toda tu carpeta y copia aparte instance/rotacion.db.
3. Descomprime el ZIP.
4. Reemplaza solamente app.py y algoritmo.py en tu proyecto.
5. Copia verificar_fase4.py a la raíz de tu proyecto.
6. Conserva tu base de datos, venv, las plantillas y los demás archivos.
7. Abre la terminal de VS Code y ejecuta:
python -m py_compile app.py algoritmo.py database.py generador.py
python probar_reglas.py
python verificar_fase4.py


El último comando comprueba las rutas de Flask y requiere que tu entorno virtual tenga Flask instalado.
Después inicia la aplicación:
python app.py


4. Qué debes probar primero
1. Entra como Líder y abre una rotación ya generada. Comprueba que se vean los operadores y sus tres estaciones.
2. Abre Cambiar estación e intenta asignar una estación para la que el operador no esté autorizado. El sistema debe rechazar el cambio.
3. Prueba una secuencia prohibida y una estación bloqueada por una restricción vigente.
4. Abre Cuentas de usuario, crea una cuenta ficticia, prueba su acceso y después desactívala.
5. Genera una propuesta de prueba y comprueba que aparezca en Historial quién la generó. Después realiza un cambio válido y comprueba que también quede registrado.
Una limitación importante: el cambio individual de estación se rechaza si deja una estación con menos operadores de los requeridos. Todavía no está implementado el intercambio simultáneo de dos operadores; esa será una mejora posterior.
